# MD Asesoría Legal — Reclamo de Papeletas

Landing page para MD Asesoría Legal, estudio jurídico en Lima especializado en
impugnación de papeletas de tránsito, suspensión/cancelación de licencias y
ejecución coactiva.

Sitio estático hecho solo con **HTML, CSS y JavaScript** (sin frameworks ni
build step).

## Estructura

```
index.html        Marcado de la página (única página)
css/styles.css     Todos los estilos
js/script.js       Carrusel del hero, menú móvil, FAQ, animaciones al hacer scroll
assets/            Favicon e imágenes
mockup/            Exploración de diseño (Design Components) — no es el sitio final
```

## Ver el sitio en local

No necesita instalación ni build. Basta con abrir `index.html` en el navegador,
o servirlo con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Deploy

Sitio 100% estático — se puede publicar gratis en [Vercel](https://vercel.com)
importando este repositorio, sin configuración adicional.
